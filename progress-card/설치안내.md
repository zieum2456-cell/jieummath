# 진도 카드 기록 — 설치·사용 안내 (1단계)

Claude가 만든 `진도카드_YYYYMMDD.csv`를 올려서 확인·수정한 뒤 **구글 시트**에 쌓는 웹 앱입니다.
Google Apps Script로 만들어서 별도 서버가 필요 없고, 데이터는 선생님 구글 계정의 시트·드라이브에만 저장됩니다.

- 아이폰: 주로 CSV 업로드
- 아이패드: 주로 확인·저장
- 아이폰에서 올린 파일은 드라이브에 보관되고 **확인 대기**로 올라가므로, 확인은 아이패드에서 이어서 하면 됩니다.

---

## 0. 넣을 파일

이 저장소의 `progress-card` 폴더에 있는 파일 6개를 씁니다.

| Apps Script 편집기에서의 이름 | 저장소 파일 | 종류 |
|---|---|---|
| `Code.gs` | `progress-card/Code.gs` | 스크립트 |
| `appsscript.json` | `progress-card/appsscript.json` | 설정(매니페스트) |
| `Index` | `progress-card/Index.html` | HTML |
| `Styles` | `progress-card/Styles.html` | HTML |
| `Core` | `progress-card/Core.html` | HTML |
| `App` | `progress-card/App.html` | HTML |

`tests` 폴더는 테스트용이라 넣지 않습니다.

**파일 내용 복사 방법 (GitHub)**: 파일을 열고 → 오른쪽 위 **Copy raw file**(겹친 네모 아이콘)을 누르면 전체가 복사됩니다.

## 1. 구글 시트 만들기 (컴퓨터에서 하는 것을 권장)

1. [drive.google.com](https://drive.google.com)에 접속합니다. 앞으로 아이폰·아이패드에서 쓸 구글 계정과 **같은 계정**이어야 합니다.
2. 왼쪽 위 **＋ 새로 만들기 → Google 스프레드시트 → 빈 스프레드시트**를 누릅니다.
3. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 **진도카드 기록**으로 바꿉니다.

## 2. Apps Script 열기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누르면 새 탭에 편집기가 열립니다.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 **진도카드**로 바꿉니다.
3. 왼쪽 끝 **톱니바퀴(프로젝트 설정)**를 누르고, **"편집기에서 'appsscript.json' 매니페스트 파일 표시"**에 체크합니다.
4. 왼쪽 끝 **＜ ＞(편집기)** 아이콘을 눌러 편집기로 돌아갑니다.

## 3. 코드 넣기

1. **Code.gs**
   - 왼쪽 파일 목록에서 `Code.gs`를 엽니다.
   - 안에 있는 `function myFunction() {...}`을 모두 지웁니다.
   - 저장소의 `Code.gs` 내용을 붙여 넣습니다.
2. **appsscript.json**: `appsscript.json`을 열고 내용을 모두 지운 뒤, 저장소의 `appsscript.json` 내용을 붙여 넣습니다.
3. **HTML 파일 4개**: 파일 목록 위 **＋ → HTML**을 누르고 이름을 입력합니다.
   - 이름은 `Index`처럼 **확장자 없이** 입력합니다(자동으로 `.html`이 붙습니다).
   - 만들어진 파일의 기본 내용을 모두 지우고 저장소 파일 내용을 붙여 넣습니다.
   - 같은 방법으로 `Index`, `Styles`, `Core`, `App` 4개를 만듭니다. 대소문자도 똑같이 맞춰야 합니다.
4. 위쪽 **저장(디스크 아이콘)**을 누르거나 `Ctrl+S`(맥은 `⌘+S`)를 누릅니다.

## 4. 처음 설정 실행 + 권한 승인

1. 편집기 위쪽 **실행** 버튼 오른쪽의 함수 목록에서 **setup**을 고르고 **▷ 실행**을 누릅니다.
2. "승인 필요" 창이 뜨면 **권한 검토**를 누르고 계정을 고릅니다.
3. **"Google에서 확인하지 않은 앱"** 화면이 나옵니다.
   - 선생님이 직접 만든 스크립트라서 나오는 정상 화면입니다.
   - 왼쪽 아래 **고급 → 진도카드(으)로 이동(안전하지 않음)**을 누릅니다.
4. 요청하는 권한을 확인하고 **허용**(또는 **모두 선택 → 계속**)을 누릅니다. 각 권한의 용도는 다음과 같습니다.

   | 권한 | 용도 |
   |---|---|
   | 스프레드시트 보기·수정 | 기록 저장 |
   | 드라이브 파일 보기·수정 | 원본 CSV 보관 |
   | 외부 서비스 연결 | 결제일 관리 앱 명단 읽기 |
   | Cloud Datastore(데이터) 보기·관리 | Firebase에 저장된 결제일 관리 데이터 읽기. 읽기만 하고 쓰지 않습니다 |
   | 이메일 주소 보기 | 화면에 로그인 계정 표시 |

5. 아래 **실행 로그**에 `설정 완료: 시트 "진도카드 기록", 원본 폴더 "진도카드 원본" ...`이 나오면 성공입니다.
6. 시트 탭으로 돌아가서 확인합니다.
   - 아래쪽에 **학생명단 · 수업기록 · 업로드이력 · 설정** 탭 4개가 생겼는지 봅니다.
   - 드라이브에 **진도카드 원본** 폴더가 생겼는지 봅니다.

## 5. 웹 앱으로 배포

1. 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. "유형 선택" 옆 **톱니바퀴 → 웹 앱**을 고릅니다.
3. 다음과 같이 입력합니다.
   - 설명: `1단계` (아무거나)
   - **다음 사용자 인증 정보로 실행: 나(내 이메일)**
   - **액세스 권한이 있는 사용자: 나만**
     - 학생 정보가 들어 있으니 반드시 "나만"으로 둡니다. 다른 계정으로는 열리지 않습니다.
4. **배포**를 누릅니다. 권한 승인 창이 또 뜨면 4번과 같이 허용합니다.
5. **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 **복사**합니다.
   - 이 주소를 메모나 카톡 "나와의 채팅"에 보내 두면 아이폰·아이패드에서 열기 편합니다.

## 6. 아이폰·아이패드에서 열기

1. **사파리**에서 웹 앱 URL을 엽니다.
2. 구글 로그인 화면이 나오면 시트를 만든 계정으로 로그인합니다.
3. 아래쪽 **공유(□↑) → 홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.

> **"죄송합니다. 현재 파일을 열 수 없습니다" 같은 오류가 날 때**
> 사파리에 구글 계정이 **여러 개** 로그인돼 있으면 Apps Script 웹 앱이 이 오류를 냅니다(구글 쪽 알려진 문제).
> - 해결 1: [myaccount.google.com](https://myaccount.google.com)에서 다른 계정을 로그아웃합니다.
> - 해결 2: 사파리 **개인정보 보호 브라우징** 탭에서 이 계정 하나만 로그인해 엽니다.

## 7. 학생 명단 연결 (결제일 관리 앱)

1. **결제일 관리 앱**에서 학생번호를 넣습니다.
   - 학생 관리 → 각 학생 **수정** → **학생번호**에 카드의 두 자리 번호(예: `56`, `07`)를 넣고 저장합니다.
   - 결제일 관리 앱에서 구글 로그인(온라인 저장)이 켜져 있어야 합니다.
2. 진도 카드 앱 **명단** 탭 → **결제일 관리에서 불러오기**를 누릅니다.
3. 미리 보기에서 추가·변경·"불러온 명단에 없음"을 확인하고, 반영할 것만 체크한 뒤 **선택한 변경 반영**을 누릅니다.
   - 결제일 관리 앱에서 빠진 학생은 지우지 않고 **퇴원**으로만 표시합니다(기본은 체크 안 됨).
   - 번호가 없는 학생은 건너뛰고 이름을 알려 줍니다.
4. 디딤돌 레벨(기본 / 기본+유형 / 기본+응용)과 발송 조(A/B)는 지금은 시트의 **학생명단** 탭에 직접 입력합니다. 2단계에서 앱 화면에서 고칠 수 있게 합니다.

**학생번호를 바꿔야 할 때**
1. 진도 카드 앱 **명단** 탭에서 그 학생 줄의 **번호 변경**을 누르고 새 번호를 입력한 뒤 **변경**을 누릅니다.
2. "수업기록 n건도 함께 바뀝니다"라는 확인 창에서 **확인**을 누릅니다. 다음이 한 번에 바뀝니다.
   - 학생명단의 학생번호
   - 이 학생의 **수업기록**: 학생번호와 기록ID(`2026-10-09_56` → `2026-10-09_57`). 그 행의 수정일시도 기록됩니다.
   - 학생명단 메모에 "56번에서 57번으로 변경(기록 n건)"이 남습니다.
3. 아래 경우에는 바꾸지 않고 이유를 알려 줍니다.
   - 새 번호를 다른 학생이 쓰고 있는 경우(퇴원한 학생 포함. 번호는 다시 쓰지 않습니다)
   - 새 번호로 같은 날짜 기록이 이미 있는 경우
4. **결제일 관리 앱의 학생번호도 같은 번호로 따로 바꿔 주세요.**
   - 결제일 관리 앱은 읽기만 하므로 진도 카드 앱에서 바꿀 수 없습니다.
   - 안 바꾸면 다음에 불러오기를 할 때 옛 번호가 "추가"로 나옵니다. 그때는 체크를 풀고 반영하면 됩니다.
5. 확인 대기 중인 카드에 옛 번호가 적혀 있으면 "명단에 없음" 경고가 뜨니, 확인 화면에서 새 번호로 고쳐 저장합니다.

**자동 불러오기가 실패할 때 (예비 방법)**
1. 결제일 관리 앱 → **설정·백업 → 진도카드용 명단 복사**를 누릅니다.
2. 진도 카드 앱 **명단 → 붙여넣어 불러오기**에 붙여 넣고 **미리 보기**를 누릅니다.

실패 메시지에 따라 이렇게 확인하세요.
- `403` / `Permission denied`:
  - Firebase 프로젝트(jieummath)를 만든 구글 계정과 이 웹 앱 계정이 다를 때 납니다.
  - [Firebase 콘솔](https://console.firebase.google.com) → jieummath → 톱니바퀴 **프로젝트 설정 → 사용자 및 권한**에서 이 계정을 **편집자**로 추가하면 해결됩니다.
- `has not been used in project` / `API`가 들어간 메시지: 메시지 안의 링크를 열어 **사용 설정**을 누르고, 몇 분 뒤 다시 시도합니다.
- 해결이 어려우면 예비 방법으로 쓰면 됩니다. 기능 차이는 없습니다.

## 8. 샘플 CSV로 확인하기

1. 저장소의 `진도카드_20261009.csv`를 아이폰 **파일** 앱에 저장합니다(또는 컴퓨터에서 그대로 씁니다).
2. **업로드** 탭 → **CSV 파일 선택** → 파일을 고릅니다. 다음과 같이 나오면 정상입니다.
   ```
   ✓ 진도카드_20261009.csv — 카드 3장 · 확인필요 1장 · 형식 오류 0장
     드라이브에 보관했습니다(진도카드_20261009.csv).
   ```
   드라이브 `진도카드 원본/2026-10/`에 원본 파일이 생깁니다.
3. **확인** 탭(아이패드에서 새로 열어도 됩니다)을 엽니다. 다음 내용을 확인합니다.
   - [ ] 목록 맨 위 **"확인필요"** 묶음에 **56 도윤**이 주황색으로 강조돼 있다.
   - [ ] 도윤 카드를 열면 주황 상자에 확인필요 3건이 나온다.
     - 지난과제가 '과제 없음'인데 지난과제범위가 있음
     - 오늘과제 판독 불확실
     - 학습태도 '첫 단어/문장' 판독 불확실
   - [ ] **지난과제범위** 칸이 노란 테두리이고 "지난과제가 '과제 없음'인데 지난과제범위가 있습니다"가 나온다.
   - [ ] 범위 칸 아래에 `디딤돌 95~97 ○ 끝냄`, `디딤돌 98 △ 하다 멈춤`처럼 해석 결과가 나온다.
   - [ ] 43 지아, 73 채아는 **문제없음**이다. 명단을 아직 안 불러왔다면 "명단에 없음" 경고가 나옵니다.
4. 시험이 끝나면 정리합니다.
   - 샘플을 실제 기록으로 남기지 않으려면 **확인 대기 파일 → 대기에서 빼기**를 누릅니다.
   - 저장까지 시험해 봤다면 시트 **수업기록** 탭에서 해당 행을 지우면 됩니다.

## 9. 매일 쓰는 순서

1. 수업 후 Claude에서 받은 CSV를 아이폰 파일 앱에 저장 → 진도 카드 앱 **업로드**
2. 아이패드 **확인** 탭에서 확인필요(주황) → 오류(빨강) → 경고(노랑) 순으로 확인·수정
   - 빨간 **오류**가 남은 카드는 저장되지 않습니다. 저장 버튼은 나머지만 저장하고, 오류 카드는 화면에 남겨 둡니다.
   - **이미 저장된 기록**이 있는 카드는 [건너뛰기 / 덮어쓰기]를 고릅니다. 기본은 건너뛰기입니다.
   - 저장하고 싶지 않은 카드는 **저장에 포함** 체크를 끕니다.
   - 고치던 내용은 그 기기에 임시 저장되므로, 화면을 닫았다 열어도 남아 있습니다.
3. **저장** → 저장 결과를 확인합니다. 실패한 카드가 있으면 이유가 나오고, 카드는 목록에 남아 있습니다.

## 10. 코드를 업데이트할 때 (재배포)

1. Apps Script 편집기에서 바뀐 파일 내용을 모두 지우고 새 내용을 붙여 넣은 뒤 **저장**합니다.
2. **배포 → 배포 관리**를 누릅니다.
3. 목록의 웹 앱을 고르고 오른쪽 위 **연필(수정)** 아이콘을 누릅니다.
4. **버전: 새 버전**을 고르고 **배포**를 누릅니다.
   - 이렇게 해야 **웹 앱 URL이 그대로**입니다.
   - "새 배포"를 누르면 URL이 바뀌니 주의하세요.
5. `appsscript.json`이 바뀐 경우(권한 추가 등)에는 편집기에서 **setup**을 한 번 더 실행해 권한을 승인합니다.
6. 아이폰·아이패드에서 앱을 닫았다가 다시 열면 새 버전이 적용됩니다.

## 11. 저장 구조

**구글 시트 "진도카드 기록"**

| 탭 | 내용 |
|---|---|
| 학생명단 | 학생번호, 이름, 학년, 디딤돌레벨, 발송조, 상태(재원/퇴원), 메모, 수정일시 |
