# 결제일 관리

학생별 결제일을 계산하고 결제 안내 메시지를 만들어 주는 프로그램입니다.
설치할 필요가 없습니다. `payment.html`을 브라우저(크롬, 엣지, 사파리)로 열면 바로 사용할 수 있습니다.

## 할 수 있는 일

- **학생 등록**: 이름, 학년(초3~고3 중 선택, 결제 현황·학생 목록에 표시), 등원 요일, 회당 수업시간(60·90·120분 중 선택), 결제 기준(12회(주3일) / 8회(주2일)), 이번 회차 수업 시작일, 원비(`35만`처럼 입력, 결제 현황·학생 관리 탭에 표시)
- **결제 현황**: 모든 학생을 결제일 순으로 보여 줍니다. 진행 회차, 마지막 회차일, 결제일(D-day)을 표시하고, 결제일이 지났거나 다가오면 강조합니다.
- **휴강 · 결강 · 대체수업 등록** (학생 상세 화면)
  | 구분 | 회차 계산 | 결제일 |
  |---|---|---|
  | 휴강 | 세지 않음 | 미뤄짐 |
  | 결강 (회차 이월) | 세지 않음 | 미뤄짐 |
  | 결강 (회차 차감) | 1회로 셈 | 그대로 |
  | 대체수업 | 원래 날짜 대신 옮긴 날짜를 1회로 셈 | 날짜에 따라 달라짐 |
  | 보충수업 | 등록한 날짜를 1회로 추가 (요일 무관) | 앞당겨짐 |
- **전체 휴강**: 공휴일이나 학원 휴무를 한 번만 등록하면, 그날 수업이 있는 모든 학생에게 휴강으로 적용됩니다. 기간(예: 추석 연휴)으로도 등록할 수 있습니다. 그날 정상 수업하는 학생은 제외 학생으로 선택하면 되고, 등록한 뒤에도 `제외 학생` 버튼으로 바꿀 수 있습니다.
- **결제 안내 메시지**: 아래 양식으로 자동 작성하고 복사 버튼으로 복사합니다. 보내기 전에 직접 고칠 수도 있습니다.
  ```
  120분 * 8회(주2일)
  수업 시작일: 2026.11.09
  --
  휴강: 10/07(학원 휴무)
  결강: 10/12(병결), 10/14(개인사정, 회차 차감)
  대체수업: 10/19(학교 행사) → 10/24
  보충: 10/31
  ```
  - `수업 시작일`은 다음 회차 첫 수업일입니다. 휴강·결강·대체수업은 이번 회차 내역입니다.
  - 보충은 사유를 입력한 경우에만 `보충: 10/31(사유)`처럼 사유가 붙습니다.
  - 휴강/결강/대체수업/보충이 없으면 `--` 아래 부분은 생략됩니다.
  - 회차 차감 결강은 사유 뒤에 `회차 차감`이 붙어 구분됩니다.
  - 설정에서 머리말·맺음말(인사말, 계좌 안내 등)을 추가할 수 있습니다. `{이름}`, `{결제일}`, `{마지막회차}`, `{다음시작일}`을 넣으면 자동으로 바뀝니다.
- **결제 완료 처리**: `결제 완료 · 다음 회차 시작`을 누르면 다음 회차 첫 수업일이 새 수업 시작일이 되고 결제 이력에 기록됩니다. 잘못 눌렀으면 `직전 처리 취소`로 되돌릴 수 있습니다.

## 결제일 기준

설정에서 고를 수 있습니다.
- **다음 회차 첫 수업일** (기본값): 12회(8회)를 모두 마친 뒤 첫 수업일
- **마지막 회차 수업일**: 12번째(8번째) 수업일

메시지에 나오는 휴강·결강·대체수업은 이번 회차 시작일부터 다음 회차 시작 전날까지의 내역입니다.

## 데이터 저장

데이터는 사용하는 브라우저 안(localStorage)에 저장됩니다. 구글 로그인을 하면 온라인(Firebase)에도 저장됩니다(아래 '온라인 저장' 참고).
다른 컴퓨터로 옮기거나 브라우저 데이터를 지우기 전에 **설정 · 백업 → 백업 파일 받기**로 백업해 두세요.

## 수업 시간표

`timetable.html`을 열면 월~토요일 시간표를 한 화면(인쇄 시 A4 한 장)으로 볼 수 있습니다.

- 배치: 1행 월·화, 2행 수·목, 3행 금·토
- 시간 칸: 월~금은 15:00~20:00 30분 단위, 20:00~22:00 1시간 단위 / 토요일은 10:00~16:00 30분 단위
- 토요일 범위(10:00~16:00) 밖에 입력돼 있던 시간은 시간표에 나오지 않고, 학생 목록에 빨간색(⚠)으로 표시됩니다. `수정`을 눌러 고쳐 주세요.
- 학생마다 요일별 등원·하원 시각을 입력하면, 요일별로 학생이 막대로 표시됩니다. 시간이 겹치는 학생은 옆 줄에 나란히 놓이고, 시간 옆에는 그 시간에 있는 학생 수가 나옵니다.
- 같은 학생은 모든 요일에서 같은 열에 놓입니다. 그래서 모든 요일의 열 수가 같고, 어떤 요일에는 빈 열이 생길 수 있습니다. 열 수는 그 조건을 지키는 범위에서 가장 적게 잡습니다.
- 등원 시각을 고르면 `기본 수업시간`만큼 하원 시각이 자동으로 채워집니다.
- 학생 이름 앞에 학년(예: `초3 김지음`)이 표시됩니다. 학년은 결제일 관리의 학생 관리 탭에서 입력한 값을 **이름이 같은 학생**에서 가져옵니다. 결제일 관리에서 학년을 바꾸면 시간표에도 바로 반영됩니다(로그인했다면 다른 기기에서도).
- `결제일 관리 학생 이름 불러오기`로 결제일 관리에 등록된 학생 이름을 가져올 수 있습니다(같은 브라우저에서 사용할 때).
- `인쇄 / PDF 저장`을 누르면 시간표만 A4 세로 한 장으로 인쇄됩니다.
- 데이터는 결제일 관리와 따로 브라우저 안에 저장됩니다. 백업 파일도 따로 받아 두세요.

## 온라인 저장 (구글 로그인)

구글 계정으로 로그인하면 데이터가 온라인(Firebase)에 저장되어, 어느 컴퓨터·휴대폰에서든 같은 주소로 로그인하면 같은 데이터를 보고 고칠 수 있습니다. 한쪽에서 고치면 다른 쪽에도 바로 반영됩니다.

- 화면 오른쪽 위 `구글 로그인 (온라인 저장)`을 누르면 됩니다. 결제일 관리와 수업 시간표에서 각각 한 번씩 로그인합니다(같은 주소라 보통 한 번 하면 둘 다 로그인됩니다).
- 처음 로그인할 때 이 브라우저의 데이터가 온라인에 올라갑니다. 다른 기기에서 처음 로그인하면 온라인 데이터를 불러옵니다. 그 기기에도 다른 데이터가 있었다면 어느 쪽을 쓸지 물어보고, 온라인 데이터를 쓰는 경우 기존 데이터는 백업 파일로 내려받아 둡니다.
- 인터넷이 끊겨도 계속 쓸 수 있고, 다시 연결되면 저장됩니다. 두 기기에서 동시에 고치면 나중에 저장한 쪽이 남습니다.
- 데이터는 로그인한 본인만 읽고 쓸 수 있습니다(`firestore.rules`). 공용 컴퓨터에서는 로그아웃할 때 이 컴퓨터의 데이터도 지우세요.
- `firebase-config.js`가 비어 있으면(`null`) 지금처럼 이 브라우저에만 저장합니다.

### 처음 설정 (한 번만)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름 예: `jieummath`, Google 애널리틱스는 꺼도 됨)
2. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **Google** 사용 설정 후 저장
3. Authentication **설정 → 승인된 도메인 → 도메인 추가**: `zieum2456-cell.github.io`
4. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, **프로덕션 모드**)
5. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 **게시**
6. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`)** 으로 앱 등록 (Firebase 호스팅은 체크하지 않음) → 나오는 `firebaseConfig` 값을 `firebase-config.js`의 `null` 자리에 넣기

`firebaseConfig` 값은 공개되어도 괜찮습니다. 데이터 보호는 5번의 보안 규칙이 합니다.

## 개발

```
npm test   # 결제일·시간표 계산, 온라인 저장 판단 로직 테스트 (Node 18 이상)
```

- `payment.js` — 결제일 계산과 메시지 생성 로직
- `app.js` — 화면 처리
- `payment.html` — 화면 구성
- `timetable.js` / `timetable-app.js` / `timetable.html` — 수업 시간표 (계산 로직 / 화면 처리 / 화면 구성)
- `cloud.js` — 구글 로그인 + 온라인 저장(Firebase), `firebase-config.js` — Firebase 설정값, `firestore.rules` — 데이터 보안 규칙
