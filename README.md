# 결제일 관리

학생별 결제일을 계산하고 결제 안내 메시지를 만들어 주는 프로그램입니다.
설치할 필요가 없습니다. `index.html`을 브라우저(크롬, 엣지, 사파리)로 열면 바로 사용할 수 있습니다.

## 할 수 있는 일

- **학생 등록**: 이름, 등원 요일, 회당 수업시간(분), 결제 기준(12회(주3일) / 8회(주2일)), 이번 회차 수업 시작일
- **결제 현황**: 모든 학생을 결제일 순으로 보여 줍니다. 진행 회차, 마지막 회차일, 결제일(D-day)을 표시하고, 결제일이 지났거나 다가오면 강조합니다.
- **휴강 · 결강 · 대체수업 등록** (학생 상세 화면)
  | 구분 | 회차 계산 | 결제일 |
  |---|---|---|
  | 휴강 | 세지 않음 | 미뤄짐 |
  | 결강 (회차 이월) | 세지 않음 | 미뤄짐 |
  | 결강 (회차 차감) | 1회로 셈 | 그대로 |
  | 대체수업 | 원래 날짜 대신 옮긴 날짜를 1회로 셈 | 날짜에 따라 달라짐 |
- **전체 휴강**: 공휴일이나 학원 휴무를 한 번만 등록하면, 그날 수업이 있는 모든 학생에게 휴강으로 적용됩니다. 기간(예: 추석 연휴)으로도 등록할 수 있습니다.
- **결제 안내 메시지**: 아래 양식으로 자동 작성하고 복사 버튼으로 복사합니다. 보내기 전에 직접 고칠 수도 있습니다.
  ```
  2시간 * 12회
  수업 시작일: 2026.10.05
  --
  휴강: 10/07(학원 휴무)
  결강: 10/12(병결), 10/14(개인사정, 회차 차감)
  대체수업: 10/19(학교 행사) → 10/24
  ```
  - 휴강/결강/대체수업이 없으면 `--` 아래 부분은 생략됩니다.
  - 회차 차감 결강은 사유 뒤에 `회차 차감`이 붙어 구분됩니다.
  - 설정에서 머리말·맺음말(인사말, 계좌 안내 등)을 추가할 수 있습니다. `{이름}`, `{결제일}`, `{마지막회차}`, `{다음시작일}`을 넣으면 자동으로 바뀝니다.
- **결제 완료 처리**: `결제 완료 · 다음 회차 시작`을 누르면 다음 회차 첫 수업일이 새 수업 시작일이 되고 결제 이력에 기록됩니다. 잘못 눌렀으면 `직전 처리 취소`로 되돌릴 수 있습니다.

## 결제일 기준

설정에서 고를 수 있습니다.
- **다음 회차 첫 수업일** (기본값): 12회(8회)를 모두 마친 뒤 첫 수업일
- **마지막 회차 수업일**: 12번째(8번째) 수업일

메시지에 나오는 휴강·결강·대체수업은 이번 회차 시작일부터 다음 회차 시작 전날까지의 내역입니다.

## 데이터 저장

데이터는 사용하는 브라우저 안(localStorage)에만 저장되고 외부로 전송되지 않습니다.
다른 컴퓨터로 옮기거나 브라우저 데이터를 지우기 전에 **설정 · 백업 → 백업 파일 받기**로 백업해 두세요.
