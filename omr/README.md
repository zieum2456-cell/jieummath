# 진도 OMR 카드 판독·기록 프로그램

수업이 끝난 뒤 진도 카드를 아이폰으로 찍으면, 카드를 한 장씩 분리해 OMR 칸과 손글씨를 읽고,
확인 화면에서 고친 뒤 학생별·날짜별 기록으로 저장합니다.

- 공부방 맥에서 실행하는 프로그램입니다. 기록과 사진은 모두 맥 안(`data` 폴더)에 저장됩니다.
- 밖으로 나가는 데이터는 **손글씨 영역만 잘라낸 이미지**를 Claude API로 보내는 것 하나뿐입니다.
  OMR 칸(학생 번호·출결 등)은 맥 안에서 판독합니다.
- 공부방 와이파이에 연결된 기기에서만 접속됩니다.

## 1. 설치 (처음 한 번)

1. **Python 설치**: https://www.python.org/downloads/ 에서 노란 `Download Python 3.x` 버튼 → 내려받은 파일을 열어 설치.
2. **이 폴더 준비**: 저장소의 `omr` 폴더를 맥의 원하는 곳(예: `문서`)에 둡니다.
3. **`설치.command` 더블클릭**
   - "확인되지 않은 개발자" 경고가 나오면: 파일을 **오른쪽 클릭 → 열기 → 열기**.
   - 몇 분 걸립니다. 끝나면 `config.toml`이 텍스트 편집기로 열립니다.
4. **API 키 넣기**: https://console.anthropic.com 에서 API 키를 발급받아 `config.toml`의
   `anthropic_api_key = ""` 따옴표 안에 붙여 넣고 저장합니다.
   - 키가 없어도 프로그램은 동작합니다 (OMR 칸만 읽고, 손글씨는 확인 화면에서 직접 입력).

## 2. 실행

1. **`실행.command` 더블클릭** → 터미널 창이 열리고 아래처럼 나옵니다.
   ```
    진도 카드 프로그램이 켜졌습니다
      이 컴퓨터에서:   http://localhost:8000
      휴대폰·아이패드: http://192.168.0.12:8000
   ```
2. 처음 실행할 때 맥이 "Python이 들어오는 네트워크 연결을 허용하겠습니까?"라고 물으면 **허용**을 누릅니다.
   (거부했다면: 시스템 설정 → 네트워크 → 방화벽 → 옵션에서 Python을 '들어오는 연결 허용'으로 바꿉니다.)
3. 터미널 창을 닫거나 `Control + C`를 누르면 프로그램이 꺼집니다. 쓰는 동안에는 창을 열어 두세요.

### 휴대폰·아이패드에서 접속할 주소 찾기

- 프로그램을 켜면 터미널에 나오는 `휴대폰·아이패드:` 주소를 사파리 주소창에 그대로 입력합니다.
- 터미널을 못 봤다면: 맥의 **시스템 설정 → Wi-Fi → 연결된 와이파이 옆 `세부사항…` → IP 주소**
  (예: `192.168.0.12`) 뒤에 `:8000`을 붙입니다 → `http://192.168.0.12:8000`
- 아이폰·아이패드가 **공부방 와이파이에 연결**되어 있어야 합니다 (데이터 통신으로는 접속 안 됨).
- 사파리에서 공유 버튼 → **홈 화면에 추가**하면 앱처럼 바로 열 수 있습니다.
- 맥의 IP 주소가 가끔 바뀌면 주소도 바뀝니다. 공유기 설정에서 맥에 "고정 IP(DHCP 예약)"를 걸어 두면 편합니다.
- 맥이 잠자기에 들어가면 접속이 끊깁니다. 수업 시간에는 시스템 설정 → 배터리(또는 에너지 절약)에서 잠자기를 막아 두세요.

## 3. 사용법

### 촬영 (아이폰)
- **카드 촬영** → 카메라가 열림 → 찍기 → `사진 사용` → 바로 올라가고 `카드 3장 중 3장 인식`이 표시됩니다.
- 다시 **카드 촬영**을 눌러 다음 장을 이어서 찍습니다. 한 사진에 카드 여러 장(최대 8장)을 찍어도 됩니다.
- 앨범에 있는 사진(HEIC 포함)은 **앨범에서 선택**으로 여러 장 한꺼번에 올립니다.
- `3장 중 2장 인식`처럼 덜 잡히면 그 카드만 다시 찍습니다. 잘 찍는 요령:
  - 카드 네 모서리의 검은 사각형이 **모두** 화면 안에 들어오게
  - 카드끼리 겹치지 않게, 어두운 책상 위에 놓고 위에서 똑바로
  - 그림자가 기준점을 가리지 않게

### 확인 (아이패드·컴퓨터)
- 위쪽에 확인할 카드가 `56 도윤 ②`처럼 나옵니다. 빨간 숫자는 **확인 필요** 항목 수입니다.
- 왼쪽(휴대폰은 위)에 카드 이미지, 오른쪽에 판독 결과가 나옵니다. 사진을 누르면 크게 보입니다.
- 손글씨 칸마다 그 부분을 잘라낸 이미지가 함께 나오니, 빨갛게 표시된 칸만 보고 고친 뒤 **저장**합니다.
- 고친 칸은 사유에 줄이 그어집니다. 수업일자는 촬영일이 기본값이고 바꿀 수 있습니다.
- 자동으로 "확인 필요"가 뜨는 경우
  - OMR: 한 칸만 골라야 하는데 두 칸 칠함 / 칠했는지 애매함 / 아무것도 안 칠함
  - 손글씨: Claude가 확신이 낮다고 답한 부분, 펜 색이 불분명한 범위
  - 지난 과제가 `과제 없음`인데 초록 펜 범위가 적혀 있음
  - 학생 번호가 명단에 없음, 손글씨 이름이 명단의 그 번호 학생과 다름
  - 같은 학생·같은 날짜 기록이 이미 있음 (저장할 때 **덮어쓰기 / 둘 다 남기기** 선택)
  - 하원 시간이 등원 시간보다 빠름
- 잘못 찍힌 카드는 **버리기** (오른쪽 위 목록에서 `버린 카드`를 고르면 되살릴 수 있음).
- 저장한 카드도 `저장됨` 목록에서 다시 열어 고칠 수 있습니다.

### 학생 명단
- **명단** 화면에서 번호(카드의 2자리 학생 번호), 이름, 학년, 디딤돌 레벨, 발송 조를 등록합니다.
- 명단에 있는 번호만 저장할 수 있습니다. 그만둔 학생은 삭제 대신 `재원 중` 체크를 끄세요.

## 4. 데이터와 백업

- `data/jieum.db` 파일 하나에 모든 기록이 들어 있습니다. 이 파일을 복사해 두면 백업입니다.
  (프로그램을 끈 상태에서 복사하세요.)
- 원본 사진(`data/photos`)과 카드 이미지(`data/cards`)는 **3개월(90일)이 지나면 자동 삭제**됩니다.
  수업 기록은 지워지지 않습니다. 기간은 `config.toml`의 `photo_retention_days`로 바꿉니다.

## 5. 판독 결과 표로 보기 (점검용)

터미널에서 이 폴더로 이동한 뒤:

```
.venv/bin/python tools/read_sample.py ../IMG_6549.pdf --expect 56,43,73
```

저장하지 않고 판독 결과만 표로 출력합니다. API 키가 있으면 손글씨 결과도 함께 나옵니다.

## 6. 개발자용 메모

- 구조: `app/vision`(기준점 찾기·원근 보정 `markers.py`, OMR `omr.py`, 손글씨 `handwriting.py`),
  `app/checks.py`(확인 필요 규칙), `app/db.py`(SQLite), `app/main.py`(웹 API), `app/static`(화면).
- 칸 좌표 `app/vision/template.json`은 카드 양식 PDF에서 만듭니다. 양식을 바꾸면:
  `.venv/bin/python tools/build_template.py ../진도_OMR_카드_A4_4장.pdf`
- 테스트: `.venv/bin/python -m pytest`
